# Icon sources

Brand logos are from [Devicon](https://github.com/devicons/devicon) (MIT; see LICENSE-DEVICON.txt), except Claude, from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/claude.svg) ([CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md)). Pandas and SQLAlchemy dark details are lightened for readability; Claude uses a terracotta fill.

The network, tree, tuning, medical, feature-grid, timeline and database pictograms are original illustrations for this README. They represent methods and tools that do not use a bundled brand logo.
